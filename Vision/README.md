## Course Structure

### HW1: Fundamental Computer Vision Techniques
**Focus**: Traditional computer vision methods and basic image processing

**Topics Covered**:
- **Optical Character Recognition (OCR)**
  - Text extraction from license plates
  - Multiple OCR engine comparison (EasyOCR, Tesseract)
  - Image preprocessing for improved OCR accuracy
  
- **Object Detection and Counting**
  - Star detection in astronomical images
  - Morphological operations for noise reduction
  - Contour analysis for object counting
  - Parameter optimization for detection accuracy

**Learning Objectives**:
- Master fundamental image processing operations
- Understand OCR pipelines and text extraction
- Learn morphological operations and their applications
- Develop skills in contour analysis and object detection
- Practice parameter tuning for computer vision algorithms

## Key Technologies Used
- **OpenCV**: Core computer vision library for image processing
- **EasyOCR**: Modern OCR library for text extraction
- **Tesseract**: Traditional OCR engine for comparison
- **Matplotlib**: Visualization and result presentation
- **NumPy**: Numerical computations and array operations

## Course Learning Outcomes
This Vision course component establishes foundational knowledge in:

1. **Image Processing Fundamentals**
   - Grayscale conversion and color space transformations
   - Image filtering and noise reduction techniques
   - Thresholding and binary image operations

2. **Morphological Operations**
   - Erosion and dilation for shape modification
   - Opening and closing for noise removal
   - Morphological gradients for edge detection

3. **Feature Detection and Extraction**
   - Contour detection and analysis
   - Object property measurement (area, perimeter, circularity)
   - Region of interest (ROI) selection and processing

4. **Optical Character Recognition**
   - Text localization in natural images
   - Character segmentation and recognition
   - OCR accuracy optimization through preprocessing

## Prerequisites
- Basic understanding of Python programming
- Familiarity with NumPy and array operations
- Mathematical foundations in linear algebra
- Basic knowledge of image representation (pixels, color channels)
